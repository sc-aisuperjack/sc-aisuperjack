## What I care about technically

**Architecture over demos.** I want clear boundaries, contracts, state, tools and failure behaviour.

**Grounding over guessing.** Retrieval, provenance and citations matter where factual accuracy matters.

**Evaluation over vibes.** Prompts and agent behaviour should be regression-tested and reviewable.

**Business behaviour over AI jargon.** Users should describe what they need naturally; the system should handle the technical structure underneath.

**Production over prototypes.** Authentication, observability, versioning, deployment and operational constraints matter.
